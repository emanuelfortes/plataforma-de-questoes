## Como pedir à IA

Use o prompt de `docs/PROMPT-CLAUDE-CERTO-ERRADO.md`, um pedido por área, com até 25 itens por pedido (acima disso a IA começa a repetir). No campo **Assunto** do pedido, use o nome da área **exatamente** como está na tabela, para as questões entrarem na pasta certa. Comece pelas áreas com 0 (marcadas com **zero**).

Depois de importar em /admin, peça para rodar de novo este levantamento (os números da tabela são de 22/10/2026).
